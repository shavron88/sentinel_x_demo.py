# 🎯 Project Mission

SentinelX transforms ordinary CCTV cameras into intelligent surveillance systems.

Instead of simply recording video, SentinelX continuously analyses live footage using AI to detect suspicious behaviour, generate alerts, preserve evidence, and provide operators with real-time situational awareness.

The MVP focuses on proving that an existing CCTV system can be upgraded with AI software without replacing the cameras.
