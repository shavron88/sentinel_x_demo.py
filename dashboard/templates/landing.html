// 03 — how it works

From camera to dashboard in seconds

A step-by-step look at how Sentinel-X processes camera feeds and delivers security intelligence.

01
Connect your camera
Add webcam, IP camera, or RTSP stream sources through the dashboard. Sentinel-X supports multiple input types.
02
Stream ingestion
Sentinel-X receives the video stream and queues frames for processing using an optimized capture pipeline.
03
AI frame analysis
The YOLO11 inference engine processes each frame, detecting objects with confidence scores and bounding boxes.
04
Object tracking
ByteTrack assigns consistent IDs to detected objects, enabling movement tracking across consecutive frames.
05
Event generation
Detection results are classified into event types — person detected, crowd forming, restricted entry, and more.
06
Threat severity assessment
Each event is assigned a severity level — Low, Medium, High, Critical — based on event type, zone, and confidence.
07
Alert triggering
High-severity events trigger real-time alerts visible on the dashboard, with optional notification delivery.
08
Evidence storage
Screenshots, event metadata, and timestamps are stored in the evidence database for later review and export.
09
Dashboard investigation
Security personnel review events, search incidents, examine evidence, and analyze trends from the web dashboard.

// 06 — responsible disclosure

Limitations & responsible use

Transparency about what Sentinel-X can and cannot do. Understanding these limitations is important for effective deployment.

AI detection can produce false positives and false negatives. No AI system is infallible.

Camera quality, resolution, angle, and lighting conditions significantly affect detection accuracy.

Processing performance depends on available hardware — GPU acceleration improves throughput substantially.

Network cameras require a stable, reliable connection for consistent detection performance.

AI surveillance should be deployed transparently and in line with workplace or facility policy.

Privacy, authorization, and applicable local laws must be respected when deploying surveillance systems.

// 09 — security & privacy

Built-in protections

Sentinel-X implements fundamental security controls for access management and data handling.

Authentication
Session-based authentication with configurable timeout. All users must sign in to access the dashboard.
Protected Dashboard
Every dashboard route is protected behind authentication. Unauthenticated visitors are redirected to sign in.
Controlled Access
CSRF token protection on state-changing operations, with rate limiting on authentication endpoints.
Evidence Management
Event evidence is stored in a structured database with timestamps, camera references, and integrity hashing.
Event History
A complete audit trail of detected events, with severity classification, camera source, and zone information.
Responsible AI
AI detection results are shown with confidence scores. The system is designed to assist, not replace, human judgment.
